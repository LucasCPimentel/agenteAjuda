# Base de Conhecimento

Esta base foi organizada em tres temas para melhorar a recuperacao do RAG.

## rag

Materiais sobre Retrieval-Augmented Generation, recuperacao, chunking, embeddings
e boas praticas para sistemas RAG.

## ia-geral

Materiais introdutorios e intermediarios sobre inteligencia artificial, incluindo
busca, aprendizado de maquina e fundamentos gerais.

## arquitetura

Materiais sobre arquitetura de software aplicada a sistemas de IA, requisitos para
sistemas de IA, planejamento e arquiteturas de colaboracao humano-IA.

## n8n

Materiais sobre agentes, RAG, contexto relevante e automacoes de IA com n8n,
incluindo documentacao oficial em Markdown e PDFs complementares.
